# 新しいブログを開設しました

どうも、利根川です。

このブログは、**PHP + Markdown + PNG** で制作しています。
記事の追加や編集は、リポジトリの `src/blog/posts/` ディレクトリ内に `.md` ファイルを作成・編集するだけで完了します。

---

## 開発フローと特徴

1. **AIいらずな制作フロー**: 手動でテキストファイルを作成・編集し、`git push` するだけで更新可能です。
2. **高速・軽量**: 静的HTMLにビルドしてVercel等の無料ホスティングで配信されるため、表示速度が高速です。
3. **画像の埋め込み**: `public/images/` に保存した PNG 画像を Markdown から簡単に埋め込むことができます。

### 画像の埋め込み例

```markdown
![サンプル画像](/images/sample.png)
```
