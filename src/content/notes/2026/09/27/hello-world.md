# 新しいブログを開設しました

どうも、利根川です。

開設時、このブログは **PHP + Markdown + PNG** で制作していました。現在は Astro に移行し、記事は Markdown のまま管理しています。
記事はリポジトリの `src/content/notes/` ディレクトリ内に `.md` ファイルを作成・編集して追加できます。

---

## 開発フローと特徴

1. **シンプルな制作フロー**: Markdown ファイルを手動で作成・編集して更新します。
2. **静的サイト**: `npm run build` で HTML を生成し、`dist/` をホスティングで配信します。
3. **画像の埋め込み**: `public/images/` に保存した PNG 画像を Markdown から簡単に埋め込むことができます。

### 画像の埋め込み例

```markdown
![サンプル画像](/images/sample.png)
```
