# **地獄の底に行こう**

まぁ、こうは言っていますが、要はインターネット僻地（Nostr）はいいぞってことです。

----

# なぜこんな記事を書いたの？って

バズや炎上、誰かのマイナスを追っかけて、隙さえあれば誰かの揚げ足を取る。

そんな日常に気づいたら疲れていませんか？

別に疲れていないのならいいのですが

僕は、**発言すればすぐにでも切り取られ、良いようにも悪いようにも使われ、気付かぬうちに自己への他者の評価が変化してしまう**

こんな世の中に嫌気がさしています。

## そんな「インターネットに疲れた」皆様へ

私から言えること

# 今すぐにでもNostrへ行こう

というわけです

炎上やバズなんて概念はなく、すでに分散型SNSとしての地盤や評価が構築されている**MastodonやMisskeyなどのFediverse**以上に自由です。

政治的な発言をしても特に言及されるでもなく、スルーされるだけですし。

ただし、制約が多いのも事実です。

# 制約

Nostrには以下の制約があります

- 投稿の完全削除は、既存のSNS以上に不可能であり、発言に責任を持たなければならない。
- 秘密鍵、公開鍵のペアが生成され、秘密鍵が漏る あるいは 紛失をするとログインが不可能になる。
  そのため、鍵の管理は慎重にならなければいけません。

正直、自由の代償が重いですが、現実に比べたらそこまでだと思っています。

# 余談

BitChatユーザーはもちろん、興味が湧いた方は下記サイトをもとにNostrへ来てみてはいかがでしょうか。
