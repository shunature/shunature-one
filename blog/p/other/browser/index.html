好きなブラウザのリリースチャンネル名

どうも

突然ですが、なんのブラウザを使っていますでしょうか？

私は、特にこだわりはないのですが Mozilla Firefox を使っています。

ふと、思うことはないでしょうか？

DevとかNightlyって何？

と

簡単に説明しますと、テスト段階の機能の実装であったり、何かと不安定なもののことを指します。

使うことはないですが、こう思いませんか？

そういうのってかっこよくない？

と

ですよね

今回は、個人的カッコいいバージョン名について書いていきます。

Nightly

先ほどから何度も擦っている "Nightly"

こちらは、毎晩更新される開発者バージョンで、Google Chromeでいう"Canary"というものです。

なんかかっこいいなということで、初っ端に失礼します。

Dev

Google Chromeや、いろんなブラウザなんかでよく使われる「開発者向けバージョン」であることを指します。

簡単ですねぇ、しかも覚えやすいときた。

でもかっこいい
